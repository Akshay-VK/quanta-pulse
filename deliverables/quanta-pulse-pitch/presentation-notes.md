# Presenter cues — about four minutes

1. **Less Quanta. More studying. (20 seconds)**
   You open Quanta because you need the material. Pulse is a local-first desktop tracker that helps you keep up with course resources and get back to studying.

2. **The refresh ritual (30 seconds)**
   “Did they upload anything?” is a familiar question. You visit course pages, try to remember what was there last time, and hunt for a file you know you saw. Describe the student's friction without blaming faculty or claiming everyone has the same experience.

3. **Today (25 seconds)**
   Start from changes. Point to the new and updated resource labels in the demo capture. On the first scan, existing resources form a baseline rather than appearing as a flood of new items.

4. **Library (25 seconds)**
   Point out the course/file hierarchy. Local copies help keep downloaded material within reach. Do not imply every resource is automatically cached or that Quanta itself works offline.

5. **Inspect and preview (25 seconds)**
   Open a resource to see its details and preview supported formats. Other formats may need an external application or the original resource.

6. **Keyboard palette (20 seconds)**
   The command palette makes view navigation and actions accessible from the keyboard. Do not describe it as full-text search through course documents.

7. **Activity Calendar (20 seconds)**
   This is a record of activity by date. History provides another way to revisit changes. It is not a schedule of upcoming submission deadlines.

8. **Course monitoring (20 seconds)**
   Choose which courses Pulse monitors. Mention the light and dark themes as a small everyday comfort. Keep session/authentication promises out of the presentation.

9. **Quiet by design (30 seconds)**
   Tracking state stays local. There is no new Pulse account to create; students use their existing Quanta access. The baseline and course controls help make the experience manageable. Live syncing still depends on network access and a valid Quanta session.

10. **Download (20 seconds)**
    The official project release has the signed Windows x64 installer for v0.3.0. Click the button or use the visible GitHub URL. Invite students to try it for their next course-material check. This is an independent project, not an official BITS Pilani product.

## Delivery

Keep the screenshots on screen while speaking; do not read all interface text. Every capture uses demo course data. The main story is “check what changed, find the material, get back to studying.” Total planned time: approximately 3 minutes 55 seconds, plus pauses.
