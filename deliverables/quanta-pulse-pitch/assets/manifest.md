# Quanta Pulse v0.3.0 screenshots

All files are full-window PNG captures at a 1600 × 1000 CSS viewport and 2× device scale (3200 × 2000 pixels). The screenshots show the released frontend at commit `fb3fc9d885126fa0825af6bc8e410d6efbc7c9b7` (release v0.3.0), rendered in Chromium with the dark theme. They were captured through the app's real UI using a temporary local Vite server and an external mocked Tauri API; no production demo mode or real credentials were used. The app source tree was not modified.

The courses, files, dates, events, local-copy records, and student identity shown are concise synthetic demo data. They are illustrative UI content, not real student activity or verified course materials. The UI itself was not edited or overlaid. The “first scan” state represents the baseline behavior in the product; pre-existing resources are known and the baseline does not emit a new-resource flood.

| File | Contents |

| `today.png` | Today activity feed with new and updated files, course labels, and the baseline note. |
| `library.png` | Course list with monitoring status and resource counts. |
