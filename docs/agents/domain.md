# Domain and decision records

Use `AGENTS.md` for project vocabulary and architecture. Consult `GLOSSARY.md` and `docs/adr/` when those project references exist; do not create them as part of an unrelated feature.

For durable decisions, read `docs/wiki/index.md` and the linked dated page before adding a claim. The wiki records dated decisions and evidence; GitHub Issues record live work state. Preserve historical claims and add a dated superseding entry when a decision changes. Cite the repository commit for claims about code.
