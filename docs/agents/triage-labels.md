# Triage labels

| Skill role | GitHub label |
| --- | --- |
| needs-triage | needs-triage |
| needs-info | needs-info |
| ready-for-agent | ready-for-agent |
| ready-for-human | ready-for-human |
| wontfix | wontfix |

Create a canonical label only when a tracker workflow needs it and it is missing. Content labels such as `bug`, `enhancement`, `accessibility`, and `documentation` may supplement triage state; they do not replace it.
