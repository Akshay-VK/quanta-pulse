# B08A — Native SSO attempt lifecycle

Implements only the native lifecycle portion of B08 at accepted base `34cbe7dee8d111b2c1e055665a9204f838714baa`.

- Parent: B08 umbrella issue #44 under #14.

## Acceptance

Keep `start_sso_login(AppHandle) -> Result<AuthStatus,String>` as a completion promise. Duplicate starts join the same result/window. Active attempts have opaque IDs and unique window labels. Add idempotent `focus_sso_login(app, attempt_id)` and `cancel_sso_login(app, attempt_id)`. Cancellation is matching-ID only, closes only its window, wakes completion waiters, and permits a successor. Fence SSO session installation after remote verification while holding the lifecycle lock through the synchronous commit. A stale callback cannot commit or affect a successor. Session restart cancels only its current flow and stale guards cannot clear a newer active flag.

Test deterministic ordering with temporary state and fake native window/sink operations; no live Quanta, auth HTTP, credentials, or packaged app. Run Windows `cargo check`, focused lifecycle tests, then full `cargo test --lib` once source is stable. Native focus proof may use a blank/test-window smoke seam and must not open the production SSO URL.
