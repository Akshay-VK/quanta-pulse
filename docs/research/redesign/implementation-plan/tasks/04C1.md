## Behavior

Keep focus separate from `details.selected` and local multi-selection. J/K/arrows focus only; Enter invokes existing `details.selectChange` once; X toggles multi-selection; E/U set desired read state for the captured event IDs of selected groups or the focused group; Delete opens the existing dismissal confirmation for only those captured groups. Delete means dismiss from Inbox, never delete History or saved files. Space invokes the shared material preview intent; source/local actions remain separate. Shift+A uses the existing complete `snapshotInboxEventIds` capture path with a frozen filter; never treat loaded row IDs or a placeholder empty array as complete scope. Fetch/resolve the authoritative capture before opening its dialog. Later arrivals remain untouched.

Rows need visibly distinct keyboard-focus, inspected and multi-selected states, and the focused time slot shows the E keycap per spec. Multi-selection needs an accessible state/control; preserve valid sibling buttons and native nested course/action behavior. Restore focus by stable identity after filtering/removal, refresh and modal close; never steal focus during ordinary background refresh. Empty lists fall back to a meaningful heading/search control. Disable duplicate submissions while capture/mutation is in flight. Existing error/rollback and retained-data behavior must survive.
