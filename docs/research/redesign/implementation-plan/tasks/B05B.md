# B05B — Freeze and apply History deletion scope

Sequential follow-up to [B05A](B05A.md); do not start until B05A is accepted
and integrated. Implement only against its approved child issue.

Capture exact event and optional scan IDs (or an opaque local snapshot token)
and return authoritative counts. Mutation deletes only the captured scope in
one transaction. A changed scope requires renewed confirmation; later events
and scans must survive. Preserve resources, saved files, baselines and
unrelated markers. Cover rollback and preserved data. The History UI remains
owned by the coordinator/task 15. Downstream dependencies remain on umbrella
B05.
