## Frozen contract

`Mirror::snapshot_delete_scope(&Connection) -> Result<MirrorDeleteScope, String>` returns public camelCase `{ scopeId, count }`. `count` is captured files: confirmed current saved copies (`ok`/`kept`) plus retained version files, each as an exact indexed physical entry under the original root. Queue/attempts stay outside.

`Mirror::delete_scope(&Connection, scopeId: &str) -> Result<MirrorDeleteResult, String>` returns public camelCase `{ removed, failed: [{ resourceId, path, error }] }`. Scope membership is in-memory, bound to this Mirror instance, bounded and expiring; restart, expiry or unknown IDs reject and require new confirmation. Retry the same ID only for remaining original failures; never recapture later files. Remove completed scopes. Missing files count as idempotently removed entries without claiming bytes were unlinked. Root or saved-publication identity changes preserve successor data and return actionable failures.

Use B02 publication ownership, including its attempt identity seam, so a later publication is distinct even if path and bytes repeat. Serialize against publication with connection-before-attempt lock order. Reject traversal and symlink escapes. On filesystem or DB failure, retain matching index/version rows and report failure. A successful entry removes only its matching row. Do not clear versions, queue, resources, baseline markers, History, or uncaptured downloads. Keep the existing `delete_all` signature and remove its blanket-clear behavior by routing through the safe core where practical.
