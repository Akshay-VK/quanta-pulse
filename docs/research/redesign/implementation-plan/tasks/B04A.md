## Frozen wire contract

Rust and TypeScript DTOs use camelCase:

```ts
type ScanCourseStatus = "success" | "partial" | "failed" | "cancelled";
interface ScanDetails { scanId: number; courses: ScanCourseDetail[] }
interface ScanCourseDetail {
  courseId: number | null; courseName: string; status: ScanCourseStatus;
  startedAt: string; completedAt: string | null; steps: ScanStep[];
  error: string | null;
}
interface ScanStep {
  label: string; status: ScanCourseStatus; startedAt: string;
  completedAt: string | null; error: string | null;
}
api.scanDetails(scanId: number): Promise<ScanDetails | null>
```

`null` means the scan is legacy or has no observed details. Storage must support actual future observation without inventing historical times. Keep the schema smallest and tied to the scan row where practical. Migration must be additive, idempotent, and valid on a populated pre-change database. History deletion cleans associated details.

## Lifecycle and sanitization contract for B04B

Provide a focused DB write helper that atomically saves the observed terminal `ScanDetails` for its existing scan row. The helper accepts the exact DTO/data observed by the engine and does not create/alter aggregate scan data. Detail write failures must be returned to the caller as a DB error; they must not silently fabricate success or damage the existing scan record. Query returns no detail for missing/legacy rows, and otherwise returns the persisted DTO in stable course/step order. Deleting a scan through history cleanup deletes its details.

Sanitize error strings before persistence and before returning them through the query seam, reusing the existing redaction helper where applicable. Remove credentials, session tokens, URL values, and sensitive URL query parameters. The stored payload and returned DTO must not contain those values. Preserve safe, useful diagnostic context. Do not introduce a generic trace/event framework.

The storage boundary accepts observed terminal statuses/timestamps from B04B; it does not infer step names, partial status, cancellation time, course identity, or lifecycle times. A missing observed result remains absent.
