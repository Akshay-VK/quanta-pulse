## Frozen consumer contract

- `api.queryHistoryEvents(filter: HistoryFilter): Promise<HistoryPage>` where
  `HistoryPage = { items: ChangeEvent[]; total: number }`.
- `api.queryHistoryScans(filter: ScanFilter): Promise<ScanPage>` where
  `ScanPage = { items: ScanRun[]; total: number }`.
- `api.snapshotResourceUnreadEventIds(resourceId: number): Promise<number[]>`
- Both pages are `{ items, total }`; filters carry required numeric `offset`
  and `limit`. `HistoryFilter` additionally has optional `changeType`,
  `courseId`, `since`, `until`, and `search`. `since` is inclusive and `until`
  exclusive; both are RFC 3339 timestamps. `ScanFilter` has only `offset` and
  `limit` because the History scan recipe specifies no other scan filters.
- `HistoryChangeType` is `"new" | "updated" | "announcement" | "deadline" |
  "unavailable" | "restored" | "baseline"`. Offset is a nonnegative integer;
  page limit is an integer from 1 through 1000. Invalid filters reject through
  the Tauri command's string error. Search is a case-insensitive substring of
  event title, description, course name, or resource title.
- Event search matches title, description, course name, and resource title,
  case-insensitively. Event ordering is `detectedAt DESC, id DESC`; scans are
  `startedAt DESC, id DESC`.
- History queries exclude calendar-suppressed events and IDs at/below the
  existing History clear watermark. Scan queries preserve the scan watermark.
  Totals describe the complete filtered result before pagination. Existing
  list wrappers remain available to current UI callers.
- Resource unread snapshots include every eligible unread ID for that
  resource, regardless of pagination/list caps, Inbox dismissal, or History
  clear watermark. Exclude baseline and calendar-suppressed rows.
