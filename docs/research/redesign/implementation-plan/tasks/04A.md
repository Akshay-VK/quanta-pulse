# 04A — Material row and table visual foundation

Implements the visual portion of task 04 after accepted prerequisites 01/02/03. It owns material row density and slot styling, generic table row geometry, group header geometry, and corresponding render/source regression checks.

## Acceptance

- Material rows use 36px comfortable and 30px compact slots. Existing automatic compact activation below 800px remains intact; non-material compact rows retain their two-line treatment.
- Table body rows use 34px, including the virtualizer's estimated row size.
- Group headers occupy 28px.
- A material row orders title (unread slot, file icon, title), change tag, course pill, optional 52px mono section, local marker when present, 40px time, then actions. Course/action controls remain siblings of the detail button.
- Long titles remain shrinkable and expose their full title; inspected-row selection and separate source/local actions remain as implemented.
- No keyboard policy, group collapse, read-on-inspect, or new product state is added.
