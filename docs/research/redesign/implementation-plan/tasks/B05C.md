## Exact approved contract

```ts
api.eventsRange(from?: string, to?: string, courseId?: number,
                limit = 2000, offset = 0): Promise<ChangeEvent[]>
```

The fifth positional argument is optional and backward compatible. Invoke existing `events_range` with `{ from: from ?? null, to: to ?? null, courseId: courseId ?? null, limit, offset }`. Forward explicit offset unchanged in the API; backend owns normalization. Append `offset: Option<i64>` to the existing Rust handler; forward `Some(offset.unwrap_or(0).max(0))` through existing `EventFilter.offset`. Preserve limit default 2000 and clamp 1..5000, return `Vec<ChangeEvent>` / unchanged string rejection semantics, local `YYYY-MM-DD` conversion to half-open UTC bounds, invalid-date errors and all filter predicates.

Root explicitly approves `ORDER BY e.detected_at DESC, e.id DESC` in shared `list_events_filtered`. Prior equal raw timestamp ties were undefined. Keep raw timestamp primary order, including mixed-precision lexical behavior; B05A parsed-instant ordering stays unchanged. Membership retains History-cleared, baseline, read, Inbox-dismissed and orphan events; excludes calendar-suppressed rows and out-of-course/out-of-range events. Physical deletion removes membership. Preserve existing unread/type filtering for other DB callers. A tie crossing a bounded page may change which formerly unspecified tied row occupies it; deterministic tie selection does not introduce a visibility predicate.

Offset paging returns only the vector, with no total or transaction snapshot. For fixed data, traverse 2000-row pages until short, including an empty terminal page at exact multiples. Concurrent inserts/deletes may shift offsets and cause omissions/duplicates; tie stability does not prove atomic completeness. Root's later collector validates page size/positive unique IDs and current course/generation, publishes only after full successful traversal, and retains prior rows on failure with scope readiness false. Complete App History cannot substitute: its clear watermark hides existing Activity members.
