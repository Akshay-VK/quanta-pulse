## Action semantics and seam

J/K and arrows should update a separate focused row only: no detail selection, read acknowledgement, or preview side effect. Enter inspects (calls existing select/detail intent); X toggles multi-selection; E/U change read state; Delete requests confirmation before deletion; Space opens preview. Shift+A must capture the current scope when the command is invoked and pass that immutable scope to its dialog. These are distinct intents; they must not be aliases for `onSelect` or native row activation. No current callback represents focus movement, multi-toggle, read/unread, delete-confirmation request, preview, or captured-scope dialog. Views currently receive individual App-owned callbacks (e.g. TodayView `onSelect`, `onToggleRead`, `onPreview`); preserve App as sole executor and expose any required intent seam through a coordinator-approved interface after I01.
