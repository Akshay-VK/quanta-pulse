## Decisions and ownership

- `materialActions.ts` remains the one pure material-destination policy. Valid recorded HTTP(S) source pages take priority over resource URLs. Preview, Open saved copy, Download and open, and Open in Quanta keep distinct meanings. Orphan recorded events retain both page and file links without inventing a Resource; external-only/off-origin links never acquire local download controls. Missing source and saved-file availability remain independent.
- App owns execution through `MaterialActionsContext`: the existing MirrorProvider resolves availability, preview uses the existing surface, and guarded download/open awaits ensure-local and OS open before reporting success. The guard is shared across row, overflow and inspector activation. A missing disk file is reported before any implicit redownload and exposes the explicit download action. Existing detail-selection and local-lookup generation guards remain; late course loads also have a generation guard.
- Today, All files, course Materials/tree and Activity, Calendar Activity, History changes, palette results and the shared inspector use these owners. Selection only inspects and never acknowledges an event. Recorded scans retain their shared details. Folder/course operations remain explicit course operations. Tree titles have an accessible activation button; semantic table actions do not also select a row. Overflow and additional shortcuts are always visible, including coarse pointers. The table action column reserves room for all three controls; a browser geometry assertion guards clipping.
- `SessionViewsProvider` owns one in-memory session map. Keys distinguish Library controls, each course/view, route/folder path and internal scroll boxes. Library tab/query/course/type/sort and course tab/query/sort/type/category/expansion/position survive navigation. Query changes reach session state immediately, and repeated identical palette requests have a request identity. Complete scoped course queries refresh when the shell inventory changes without resetting context. Measured virtual rows precede internal scroll restoration. Removed selections are not restored from session memory.
- The inspector has one primary material action, optional Preview, source/change/due facts, independent local status and expandable technical file facts. Palette results display section and known saved-copy status; unsupported/oversized preview fallbacks use the shared explicit source destination. Existing public view callbacks are retained for integration compatibility; production identity-based rows supersede legacy `showOpen`/URL inference.
